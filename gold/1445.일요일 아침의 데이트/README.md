# [BOJ 1445] 일요일 아침의 데이트

- **문제:** [백준 1445번 - 일요일 아침의 데이트](https://www.acmicpc.net/problem/1445)
- **알고리즘:** 다익스트라(Dijkstra), 최단 경로
- **사용 언어:** Java

## 문제 분석

`N × M` 크기의 숲에서 시작점 `S`부터 도착점 `F`까지 이동해야 한다. 상하좌우로 이동할 수 있으며, 다음 두 조건을 **순서대로** 최소화해야 한다.

1. 쓰레기가 있는 칸(`g`)을 밟는 횟수
2. 쓰레기를 밟는 횟수가 같다면, 쓰레기와 인접한 빈칸을 지나는 횟수

여기서 *쓰레기와 인접한 칸*은 상하좌우 중 하나 이상에 쓰레기가 있는 **빈칸(`.`)** 을 의미한다. 시작점 `S`와 도착점 `F`는 쓰레기 옆에 있어도 인접 칸 횟수에 포함하지 않는다.

일반적인 최단 경로처럼 이동 횟수가 가장 적은 경로를 찾는 것이 아니라, **우선순위가 있는 두 비용을 최소화하는 경로**를 찾아야 한다.

## 핵심 아이디어

### 1. 두 가지 비용을 하나의 정수로 표현하기

쓰레기를 밟은 횟수를 `trashCount`, 쓰레기 옆을 지난 횟수를 `nearCount`라고 하면, 경로의 비용을 다음과 같이 표현한다.

```text
cost = trashCount × 10,000 + nearCount
```

각 칸에 부여하는 이동 비용은 다음과 같다.

| 칸의 종류 | 이동 비용 |
| --- | ---: |
| 쓰레기 칸 (`g`) | 10,000 |
| 쓰레기와 인접한 빈칸 (`.`) | 1 |
| 일반 빈칸 (`.`), 시작점 (`S`), 도착점 (`F`) | 0 |

예를 들어, 쓰레기 칸을 2번 밟고 인접한 칸을 3번 지난 경로의 비용은 `20,003`이다. 쓰레기 칸을 1번 밟고 인접한 칸을 100번 지난 경로의 비용은 `10,100`이다. 따라서 후자가 우선된다.

**왜 10,000이면 충분할까?**

격자 크기는 최대 `50 × 50`이므로, 사이클이 없는 경로의 이동 횟수는 최대 `2,499`번이다. 모든 이동 비용이 음수가 아니므로 최적 경로 중 사이클이 없는 경로를 선택할 수 있다. 따라서 인접 칸의 누적 비용은 10,000보다 작고, 쓰레기를 한 번 더 밟는 비용이 언제나 우선순위를 결정한다.

즉, **사전식 우선순위(쓰레기 횟수 → 인접 칸 횟수)** 를 단일 정수의 대소 비교로 처리할 수 있다.

### 2. 쓰레기 인접 칸 표시하기

입력받은 격자에서 쓰레기 칸을 먼저 `10,000`으로 표시한다. 이후 모든 쓰레기 칸의 상하좌우를 확인하여 다음 조건을 만족하는 칸만 `1`로 표시한다.

- 격자 범위 안에 있다.
- 시작점 `S`나 도착점 `F`가 아니다.
- 아직 비용이 `0`인 빈칸이다.

이미 쓰레기인 칸의 비용을 덮어쓰지 않으며, 여러 쓰레기와 인접하더라도 해당 칸의 비용은 `1`이다.

모든 이동 비용이 0 이상이므로 다익스트라를 사용할 수 있다. 우선순위 큐에서 도착점 `F`를 꺼냈을 때의 비용이 최소 비용이다.

최종 비용을 `10,000`으로 나눈 몫과 나머지를 출력한다.

## 정리

이 문제는 두 기준을 동시에 최소화하지만, 두 기준의 **우선순위가 명확하다**는 점이 핵심이다. 낮은 우선순위 비용의 최대 합보다 충분히 큰 가중치를 높은 우선순위 비용에 부여하면, 여러 기준을 하나의 정수 비용으로 인코딩할 수 있다.

이렇게 변환하면 별도의 2차원 비용 쌍을 비교하지 않고도 일반적인 다익스트라 알고리즘으로 원하는 최적 경로를 구할 수 있다. 다만 이 기법은 **낮은 우선순위 비용의 상한을 보장할 수 있을 때** 안전하게 적용할 수 있다.
